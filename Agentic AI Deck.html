BLOCK 01 · PROMPT

The prompt — your blueprint for AI behavior.

A prompt isn't a question — it's a structured instruction with five moving parts.

ROLE

Who the AI is acting as.

CONTEXT

What it needs to know first.

TASK

What you want it to do.

FORMAT

How you want the output shaped.

CONSTRAINTS

What it must and must not do.

✕ VAGUE inconsistent output

"Test this feature."

✓ STRUCTURED repeatable · reviewable

[ROLE] Act as a {QA engineer}.
[CONTEXT] Given Jira ticket {ticket},
[TASK] identify the top 5 regression risks,
[FORMAT] as a markdown table with columns
    | Area | Risk | Severity |
[CONSTRAINTS] severity ∈ {High, Med, Low}.

Principle Output quality is a direct function of prompt quality.

BLOCK 06 · PLUGINS & COMMANDS

Plugins and commands — extending what agents can do.

Two different levers: one widens the platform, the other shortcuts your workflow.

PLUGIN

Extends the platform.

Adds entirely new capabilities to the agent runtime — scheduling, observability, new tool types.

EXAMPLE · opencode-scheduler

cron("0 2 * * *", env-health-check)
→ runs nightly at 02:00, posts to Confluence.

BEST FOR

Timing · background work · new abilities.

COMMAND

Shortcuts a workflow.

A single keyword triggers a complex, multi-step agent behavior you defined once.

EXAMPLE · /init

/init
→ agent scans the project, produces a structured spec.md, drops it at repo root.

BEST FOR

Repeatable multi-step tasks · team shortcuts.

Principle Plugins extend what agents can do. Commands make complex workflows one-click.

07 · ORCHESTRATION

Three orchestration patterns.

Pick the pattern that fits the task's dependencies — not the one you used last time.

01 · SEQUENTIAL chained

A → B → C

USE WHEN

Each step depends on the previous output.

02 · PARALLEL fan-out

Spawn · merge

USE WHEN

Tasks are independent and speed matters.

03 · HIERARCHICAL lead + team

Lead · team · tools

USE WHEN

Complex domains with multiple specializations.

Principle Choose the pattern based on task dependencies — not habit.

09 · ACTION PLAN

A four-phase path forward.

Start small. Each phase builds on the last.

PHASE 01
WEEK 1–2

Master the prompt.

Write 3 structured prompts for your most common QA tasks. Test. Refine.

PHASE 02
WEEK 3–4

Run your first agent task.

Pipe your best prompt through @qa-agent with a real MCP (Jira). Measure before vs after.

PHASE 03
MONTH 2

Go multi-agent.

Split the task into 2–3 subagents. Add parallelism. Gate write actions behind human approval.

PHASE 04
MONTH 3+

AFK & autonomous.

Schedule agents to run overnight. Results land in Confluence by morning. Share the wins.

Guiding rule Don't automate everything. Automate what slows you down most.
